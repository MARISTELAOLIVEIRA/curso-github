    😎 Com Git e GitHub

    Cada mudança vira um commit: uma "foto" do projeto com data, autor e uma mensagem. Clique nos commits e viaje no tempo:

      
          
      
        
      
      
      

      
      Git ≠ GitHub
      
      
      
        
      
          📸
          
      Git
      
          
      O programa que fica no seu computador e tira as "fotos" (commits) do seu projeto.
      
          Como a câmera do celular.
        
      
        
      
          ☁️
          
      GitHub
      
          
      O site que guarda essas fotos na nuvem e mostra seus projetos para o mundo.
      
          Como o álbum online onde você publica as fotos.
        
      
      
      

      
      Por que isso importa para você
      
      
      
        
      💼PortfólioRecrutadores olham o GitHub antes da entrevista
      
        
      🛟BackupO notebook quebrou? Seu projeto está salvo
      
        
      🤝EquipeVários colegas no mesmo projeto, sem bagunça
      
        
      📚EntregasOs projetos das disciplinas são entregues por aqui
      
      
      

      
      Mini dicionário
      
      
      
        
      Repositório
      A "pasta" do projeto no GitHub, com todo o histórico.
      
        
      Commit
      Uma "foto" das mudanças, com uma mensagem explicando o que mudou.
      
        
      Push
      Enviar os commits do seu computador para o GitHub.
      
        
      Clone
      Baixar um repositório do GitHub para o seu computador.
      
        
      README
      A "capa" do projeto: o texto que aparece na página do repositório.

        Módulo 3⏱️ 15 min
        
        Seu primeiro repositório (pelo site)
        
      
        
      
        Dá para publicar um projeto sem instalar nada, só pelo navegador. É o jeito mais rápido de começar.
        

      
          
        
        1. No GitHub, clique no + (canto superior direito) → New repository
          2. 
        
        2. Repository name: o nome do projeto (teste abaixo 👇)
          3. 
        
        3. Description: uma frase sobre o projeto
          4. 
        
        4. Deixe Public marcado e ative Add README
          5. 
        
        5. Clique em Create repository 🎉
          6. 
      
        

      
        
        
        🏷️ Teste o nome do repositório
        
        
        
        
          
        O GitHub vai salvar como:—
        
          
        Nossa sugestão (minúsculas e hífens):—
        
        
        
      
        

      
        Enviando os arquivos: Add file → Upload files
        
      
        Experimente: arraste os arquivos do seu computador para o repositório (ou clique neles), escreva a mensagem do commit e confirme.
        
      
        
        
        
          
        💻 Seu computador
        
          
        
        
        
        
        
          
        ☁️ github.com/seu-nome/meu-projeto
        
          
        Solte os arquivos aqui
        
          
          
          
          
          
        
          
      
          

      
          
        ✍️
        
          Mensagem de commit boa diz o que mudou: "Adiciona formulário de contato", "Corrige o cálculo da média".
          
        Mensagem ruim: "update", "asdf", "agora vai". Daqui a um mês, você não vai lembrar o que foi! 😅
          
      
          

      
          
      
    
          

    
    
          
      
          
        Módulo 4⏱️ 30 min
        
          Git no VS Code: o dia a dia
          
      
          
      
          O upload pelo site é ótimo para começar. Mas, no dia a dia, você programa no VS Code e envia as mudanças direto de lá, com um clique.
          

      
          1. Instale o Git
          
      
          
        
          
          
          Baixe o Git for Windows em git-scm.com e instale clicando em Next até o fim (as opções padrão estão ótimas). Depois, feche e abra o VS Code.
          
        
          
        
          
          
          No Mac, o Git vem com as Ferramentas de Linha de Comando da Apple. Abra o Terminal, digite o comando abaixo e, se o Mac oferecer, clique em Instalar.
          
        
          
        
          Para conferir, no terminal do VS Code (Terminal → Novo Terminal):
          
        
          git --version
          
        
          Apareceu git version 2.…? Pronto! ✅
          
      
          

      
          2. Diga ao Git quem é você (só uma vez por computador)
          
      
          
        
          Troque pelo seu nome e pelo e-mail da sua conta do GitHub:
          
        
          git config --global user.name "Maria Silva"
          
        
          git config --global user.email "maria@email.com"
          
      
          

      
          3. Clone o repositório
          
      
            
        
          1. No GitHub, na página do repositório: botão verde Code → copie o link HTTPS
            2. 
        
          2. No VS Code: CtrlCmd+Shift+P → digite Git: Clone → cole o link
            3. 
        
          3. Escolha a pasta onde o projeto vai ficar e clique em Abrir
            4. 
        
          4. Na primeira vez, o VS Code pede para entrar com o GitHub: autorize no navegador
            5. 
      
          

      
          4. O ciclo de todo dia
          
      
          
        
          ✏️Editetrabalhe nos arquivos normalmente
          
        
          →
          
        
          ➕Preparena aba Controle do Código-Fonte, clique no + dos arquivos
          
        
          →
          
        
          📸Commitescreva a mensagem e clique em Commit
          
        
          →
          
        
          ☁️Envieclique em Sync Changes (é o push)
          
      
          

      
          5. Simulador: faça pelo terminal 🧪
          
      
          Os botões do VS Code fazem estes mesmos comandos. Siga as missões e veja os arquivos andando até o GitHub.
          
      
          
        
          
          
          📂 Sua pasta
          
          
          ➕ Preparados (staging)
          
          
          📸 Commits (no seu PC)
          
          
          ☁️ GitHub
          
        
          
        
          
          
          
            
          terminal
          
            
          
            
          
              meu-projeto $
              
            
          
          
          
          
          
            
          🎯 Missões
          
            
            
            
          
            
        
            
      
            

      
            6. O que NÃO enviar: o .gitignore
            
      
            
        
            Crie um arquivo chamado .gitignore na pasta do projeto. Tudo o que estiver listado nele o Git ignora:
            
        
            # senhas e chaves: NUNCA vão para o GitHub
.env

# pastas que são geradas ou baixadas automaticamente
node_modules/
__pycache__/
venv/
            
        
            ⚠️ Se você enviou uma senha sem querer, apagar o arquivo não basta: ela continua no histórico. Troque a senha!
            
      
            

      
            
      
    
            

    
    
            
      
            
        Módulo 5⏱️ 20 min
        
            Um README que impressiona
            
      
            
      
            O README é a primeira coisa que aparece no seu repositório. É a capa do projeto, e o que um recrutador (ou a professora 😉) vai ler primeiro.
            

      
            
        
            
          
            O que todo README precisa ter
            
          
              
            
            • 📛 Nome do projeto
              • 
            
            • 📄 O que ele faz, em 2 ou 3 frases
              • 
            
            • 🛠️ Tecnologias usadas
              • 
            
            • ▶️ Como rodar o projeto
              • 
            
            • 🖼️ Um print ou link do site
              • 
            
            • 👤 Seu nome, curso e disciplina
              • 
          
            
        
            
        
            
          
            Markdown em 1 minuto
            
          
            
            
            # Títulotítulo grande
            
            
            ## Seçãosubtítulo
            
            
            **negrito**negrito
            
            
            - itemlista
            
            
            [texto](link)link
            
            
            ![descrição](imagem.png)imagem
            
            
            `código`código

        Módulo 6⏱️ 15 min
        
            Seu site no ar com o GitHub Pages
            
      
            
      
            Fez um site em HTML, CSS e JavaScript? O GitHub publica de graça, com um link para mostrar para todo mundo. Este curso que você está vendo está no GitHub Pages! 😄
            

      
            
        ⚠️
        
            O Pages publica só sites estáticos (HTML, CSS, JavaScript, imagens). Projetos que precisam de servidor, como Python, PHP ou banco de dados, não rodam nele. Para esses, o repositório com um bom README já é a entrega.
            
      
            

      
              
        
            1. Confira se o arquivo principal se chama index.html e está na raiz do repositório (fora de qualquer pasta)
              2. 
        
            2. No repositório: Settings → Pages (no menu da esquerda)
              3. 
        
            3. Em Source, escolha Deploy from a branch
              4. 
        
            4. Em Branch, escolha main e a pasta / (root) → Save
              5. 
        
            5. Espere 1 ou 2 minutos e atualize a página: o link aparece no topo 🎉
              6. 
      
            

      
            
        
            🔗 Qual vai ser o link do seu site?
            
        
            
          
          
        
            
        
            https://seu-usuario.github.io/nome-do-repositorio/
            
      
            

      
            Bônus: seu perfil vira portfólio 🌟
            
      
            
        
            Crie um repositório com o mesmo nome do seu usuário (ex.: maria-silva/maria-silva) e marque Add README.
        Tudo o que você escrever nesse README aparece no topo do seu perfil: apresentação, tecnologias que você usa e links para os seus melhores projetos.
